# Player Guide

This describes the finished, playable behavior of this ROM hack: a solo,
replay-focused, streamlined randomized Emerald Nuzlocke. Every claim here was
checked directly against the current source during Phase 13A — if something
here and an old design note disagree, this document (and its authority,
[`SPEC.md`](SPEC.md)) is correct.

There is no Tournament mode, no Hall-of-Fame species exclusion, and no
cross-run species bans anywhere in this game. A completed run never changes
what a later fresh run can generate — every run is fully independent, and
the Hall of Fame / Run Report system is a purely informational, celebratory
archive of your own past attempts.

## Starting a run

**Recommended** is the intended way to play — it's what the developers
actually believe makes the best solo run: hardcore Nuzlocke rules, balanced
randomization across every category, Gen 9 mechanics, level caps with Level
to Cap, Infinite Repel, HM-free progression, a linearized campaign, and
maximum-strength *fair* AI. Starting a New Game with Recommended selected
gets you into the game with minimal button presses.

Two other named presets exist for different tastes, plus a fourth slot that
just means "I changed something":

| Preset | What it is |
|---|---|
| **Recommended** | The intended experience — see above. |
| **Modern Emerald** | Ordinary, non-randomized Emerald species and trainers, but with the modern Gen 9 battle engine and QoL. Story streamlining can stay on. Nuzlocke rules, caps, and most randomization are off. |
| **Randomizer** | Full randomization and QoL with no mandatory Nuzlocke restrictions — permadeath and one-per-location are off, catch rate is boosted, whiteout is ordinary Emerald whiteout. |
| **Custom** | Not a preset you can select directly — it's what the menu shows automatically the instant you change any individual setting away from whichever named preset you started from. This is where every supported setting can be tuned individually; there's no separate "Advanced" screen. |

Choosing a preset fills in every setting at once. Changing one setting
afterward flips the display to Custom without touching anything else you
picked.

### The New Game settings wizard

A genuinely new save (not a Nuzlocke whiteout retry) routes through a
dedicated one-time settings screen, separate from the ordinary in-run RULES
menu:

**New Game → naming screen → wizard (preset → seed → Generation 1–9 mask →
confirmation summary) → lock in → gameplay.**

- **Automatic seed (default):** a fresh seed is generated by mixing four
  independent sources — the game's running RNG state, a frame counter since
  boot, the console's real-time-clock fields, and a persistent counter that
  increments on every New Game and survives resets. This keeps two players
  starting at the same moment on identical hardware from landing on the same
  seed.
- **Manual seed:** press A on the seed row to open an 8-digit hex editor and
  type your own. Sharing a seed with someone else lets them regenerate the
  identical starters, wild-slot mapping, trainer parties, learnsets,
  abilities, and items — assuming the same ROM version and the same
  generation-mask/settings choices.
- **Deterministic reproduction:** a run's reproducible identity is the tuple
  (ROM/randomizer version, run seed, every generation-locked setting
  including the Gen 1–9 mask). The ruleset and randomizer format versions are
  stored with the save, so a seed stays reproducible even after a future ROM
  update, as long as neither version number changed the generation logic in
  between.
- **Generation 1–9 mask:** nine independent toggles, **default all ON**.
  A species or form is classified by the generation that *introduced that
  specific form* — Eevee is Gen 1, Sylveon is Gen 6; a regional form is
  classified by the generation that introduced that regional variant.
  Disabling a generation removes its species from every pool (wild, trainer,
  starter, gift, static, Premium) and from every evolution path, so a
  disabled generation can never be reached indirectly by evolving into it.
  Every selector safely falls back to the game's own vanilla species if a
  pool ever comes up empty, and the wizard itself refuses to start a run with
  every generation disabled.

**Which settings lock, and when.** Settings fall into three tiers:

- **Generation-locked** — everything that determines the generated world:
  species-pool details, power matching, encounter mapping, starter/gift/
  static/trainer randomization, learnset/move generation, TM/Tutor
  randomization, ability randomization, item-category randomization, and the
  battle-gimmick toggles, plus the preset/seed/generation mask themselves.
  These lock the instant the run starts and can only ever be set through the
  wizard — the in-run RULES menu shows them read-only with an "(L)" marker.
- **Nuzlocke-rule-locked** — permadeath, one-encounter-per-location, no
  battle items, forced Set battle style, cap mode, and similar hardcore
  rules lock once the run goes "strict" (the moment any of those rules is
  actually active), so you can't disable permadeath mid-run after losing
  something. Under Modern Emerald or Randomizer, where none of those rules
  are active, this tier stays editable throughout.
- **Always adjustable** — QoL and display settings (Portable Heal, Infinite
  Repel, both-bikes switching, Level to Cap, Move Reminder mode, and similar)
  can be changed from the in-run RULES menu at any time.

A Nuzlocke whiteout retry skips the wizard entirely and silently reuses the
settings already locked in for that save (rerolling the seed by default,
unless Retry Same Seed is set).

## How randomization works

Every generated category — wild species, trainer parties, starters, gifts,
statics, abilities, learnsets, TMs, Tutors, and items — is its own
deterministic stream derived from the run seed plus a distinct internal tag,
so changing one category never reshuffles an unrelated one.

### Species power and stage matching

Ordinary wild, trainer, starter, gift, and static replacements are chosen
from Pokémon of similar intrinsic power (base stats, offensive/defensive
efficiency, speed, and a few hand-tuned adjustments for species whose
canonical design is artificially held back or boosted by their ability),
preferring a similar evolutionary stage (unevolved/middle/final) where
possible. **There is no coherence, coverage, or quality floor at any tier,
including bosses.** A boss's team is not made "fair" — a Gym Leader can
legitimately roll an excellent team or a genuinely bad one, and a species'
generated learnset can be equally lopsided. Discovering a broken combination,
or getting stuck with a bad one, is part of the game.

### The Premium category

**Premium** means Legendary Pokémon, Mythical Pokémon, Ultra Beasts, and
Paradox Pokémon (and any other project-designated restricted species) as a
group. Premium species:

- **Never** appear in an ordinary wild encounter, on the rival, on Wally, on
  a Team Aqua/Magma member or admin, or on a Gym Leader.
- **May** appear at a curated set of legendary/premium static encounter
  slots (see below), and on the Elite Four or Champion Wallace's randomized
  teams — nothing is guaranteed on any single Elite Four member, but
  **Wallace is guaranteed at least one.**
- Duplicate Premium species across separate slots are allowed — two
  different Premium statics can independently land on the same species.

Every canonical premium static slot in the ROM is Premium→Premium: its
location, story trigger, and progression stay exactly where they were, but
whatever species results is drawn only from the Premium pool (the original
species itself always stays eligible). The slots are: **Rayquaza** (Sky
Pillar), **Kyogre** (Marine Cave), **Groudon** (Terra Cave), **Regirock /
Regice / Registeel** (Desert Ruins / Island Cave / Ancient Tomb, unlocked
right after the Sootopolis crisis with no puzzle to solve), **Latios and
Latias** (Southern Island), **Lugia** (Navel Rock), **Ho-Oh** (Navel Rock),
**Deoxys** (Birth Island), **Mew** (Faraway Island), and the **roamer**
(Latias or Latios, chosen by the usual TV news prompt). Access tickets for
the island encounters are handed out free by an NPC at the Slateport
harbor once the Sootopolis crisis resolves — no fetch quest gates them.

### Learnsets, abilities, TMs and Tutors

Every species gets its own generated set of **21** level-up learning
opportunities, spread across 21 even checkpoints from level 1 to level 61.
The default composition is **weighted random, not a fixed quota**: STAB
moves and higher-power attacks are more likely at later checkpoints, but
these are probabilities, not guarantees — an early powerhouse move or a late
joke move can both happen. A separate, non-default "Fixed quotas" mode
exists for players who want a literal roughly-even split of STAB/status/
coverage instead.

Abilities are randomized per species and stay consistent through an
evolutionary family (evolving never rerolls to an unrelated ability).
Shedinja always keeps Wonder Guard rather than rolling it randomly.

TMs and Move Tutors get randomized move assignments, fixed for the run, with
universal compatibility by default — every species can use every TM/Tutor
move regardless of vanilla compatibility lists.

## Nuzlocke rules

**Rules don't start until you actually hold a Poké Ball.** Before your first
Ball, wild encounters don't consume anything and fainting doesn't trigger
permadeath — there's nothing to protect yet. The moment you receive your
first Balls, every rule below activates and applies going forward, including
retroactively to whatever encounter is still unresolved at that instant.

- **Permadeath (default ON).** A fainted Pokémon is permanently dead: it
  can't battle, be revived into legal use, or provide any other gameplay
  benefit. Dead Pokémon move to a dedicated Graveyard PC box automatically;
  you can still look at them.
- **One encounter per location (default ON).** Only the first valid wild
  encounter at each distinct location can be caught. Killing it, running
  from it, or failing to catch it all consume that location exactly like
  catching it would — there's no free retry by fleeing.
- **Dupes Clause (default ON).** Once a species' entire evolutionary family
  (including split evolutions and regional/form variants) has been your
  valid encounter anywhere — caught, killed, fled, or run from — any later
  encounter from that same family is automatically a "dupe": it doesn't
  consume the new location, and the game keeps rerolling toward a
  non-duplicate species where one exists.
- **Shiny Clause (default ON).** A shiny can always be caught, regardless of
  whether the location was already used or the family already logged. It's a
  pure bonus — catching it doesn't consume the location's normal encounter
  or count as a new dupe entry.
- **Nicknames (default off).** Optionally require every obtained Pokémon to
  be nicknamed, with the naming prompt unable to be skipped or left as the
  species name.
- **No battle items (default ON).** Your Bag is unavailable during trainer
  battles — no Potions, Full Restores, X Items, status healing, Revives, or
  manually-used berries. Held items still work normally. Wild battles still
  let you throw Balls.
- **Whiteout (default: run over).** Losing with no usable Pokémon anywhere —
  not in your party, not in any PC box, not in Daycare — ends the attempt.
  You get a run-over screen and can start a fresh attempt immediately, with
  no limit on tries. A fresh attempt normally gets a new seed.
- **Forced Set battle style (default ON).** No free switch-in offered after
  knocking out an opposing Pokémon.

## Items, money, and Poké Balls

**Randomization.** Field items, hidden items, and gift items are randomized
and fixed for the run. Key/progression items, HMs, and TMs (which already
carry their own randomized move) are never touched — only ordinary
consumables, berries, and (see below) the Master Ball can result from a
randomized item slot. Excluded from the randomized pool entirely, because
they'd be redundant or actively harmful under these rules: ordinary healing
and status medicine, Revives, battle-only X-item boosters, Repels (Infinite
Repel replaces them), Rare Candies (Level to Cap replaces them), sell-only
treasure (money is unlimited), PP-restoration consumables (Portable Heal
covers that outside battle), the Mega/Z-Move/Dynamax/Tera item families
(those mechanics are off), and every Poké Ball except the Master Ball.
Held items, berries, and permanent stat boosters like Protein/PP Up/PP Max
remain eligible and can turn up purely through randomized pickups.

Every evolution stone and item this game's included species actually need is
guaranteed purchasable from a dedicated clerk on the **3rd floor of the
Lilycove Department Store**, so an unlucky item roll can never make an
evolution permanently impossible — only delayed until you reach Lilycove.

**Money is unlimited by default.** Your balance is set to the maximum on a
new save and purchases simply never reduce it — no money grinding, ever.

**The Bag is expanded** well past vanilla capacity (100 Item slots, 50 Key
Item slots, 40 Poké Ball slots, 120 TM/HM slots, 80 Berry slots, each
stacking to 999), so collecting a wide, useful item pool never runs you out
of room.

**Poké Balls.** The moment catching unlocks, an NPC in Oldale Town hands you
**999 ordinary Poké Balls** outright — no early capture-resource management.
Beyond that, Ball availability follows Emerald's own existing shop
progression unchanged (Great Ball reaching shops early-to-mid-game, Timer/
Repeat Ball from Rustboro, Ultra Ball and the remaining specialty Balls
opening up by the third badge or so) — nothing bespoke was layered on top of
it, and nothing needed to be. The **Master Ball is never sold**, and it's
the *only* Poké Ball that can ever result from a randomized field-item roll
— every other Ball comes exclusively from shop progression, never random
luck. Exactly one Master Ball is guaranteed, appearing right before the
post-Rayquaza Premium encounters unlock; an additional one can still show up
from a lucky field-item roll on top of that.

**Ball shortcut (default ON).** During a wild encounter, hold R and tap the
D-pad to cycle forward/backward through the Balls you currently own; tap R
alone to throw whatever's currently selected. It never selects a Ball you
don't own and never auto-picks the Master Ball just because you have one —
you always have to deliberately dial it in.

## Quality of life

- **Level to Cap (default ON, from the party menu or the PC box menu).**
  Instantly raises a Pokémon to the current progression cap — but not by
  simply skipping ahead. It works out every move-learning level you'd have
  crossed, jumps you to the cap, then walks you through each of those
  learning opportunities in order, exactly as if you'd leveled up normally.
  No move is ever lost. It grants no artificial EVs and **never
  auto-evolves** the Pokémon — evolving stays your own decision.
- **Move Reminder — default Disabled.** Out of the box, forgotten level-up
  moves stay forgotten; the Fallarbor Heart Scale NPC won't teach them
  either. This is deliberate — a forgotten randomized move is meant to be a
  real loss. Three other modes are available in Custom: **Normal** (the
  Fallarbor NPC works normally), **Free** and **Previously learned only**
  (both add a no-cost relearner from the Pokémon's Summary screen, opened
  with START on the Moves page).
- **Evolve command (default ON).** From the party menu, select a Pokémon and
  choose EVOLVE to trigger any evolution it's currently eligible for. Split
  evolutions let you pick which outcome you want when the original game
  would have. Evolution is always something you actively choose — Level to
  Cap never triggers it for you.
- **Portable Heal (default ON).** A menu-accessible full heal (HP, PP,
  status) that never revives dead Pokémon — reachable from the RULES field
  menu or via a dedicated key item you can register to SELECT. Removes
  Pokémon Center detours entirely.
- **Infinite Repel (default ON).** Toggle it from the RULES menu or its own
  key item. While active it silently suppresses ordinary random wild
  encounters; scripted/static encounters still happen normally. Turn it off
  whenever you actually want to search a new area.
- **Both bikes.** Rydel's Mauville bike shop hands you the Mach Bike *and*
  the Acro Bike in one visit — no return trip to swap. Switch which one
  you're riding (or which is SELECT-registered while on foot) from RULES →
  SWITCH BIKE.
- **Type icons** are shown, unconditionally, next to Pokémon on the starter
  screen, the party menu, the PC box screen, and both battle HUDs — no
  external reference needed to know what you're fighting or fielding.
- **HM-free traversal (default ON).** None of your Pokémon need to actually
  know Cut, Rock Smash, Strength, Surf, Fly, Dive, or Waterfall to use them
  on the field — permission to use each unlocks with the corresponding badge
  (in that order, Badge 1 through Badge 8), and any living, non-dead party
  member can perform the interaction once it's unlocked. Flash likewise
  unlocks with Badge 2. HM moves themselves can still be taught, used in
  battle, and forgotten like any other move; the field interaction and the
  battle move are fully decoupled.
- **Quick Travel (default ON).** Unlocks right after rescuing Peeko at
  Rusturf Tunnel, alongside PokéNav. Open your PokéNav's MAP screen (or the
  Town Map item screen, if you ever get one) and press R over any town or
  city you've already legitimately visited to warp there instantly. It never
  lets you travel somewhere you haven't actually reached yet — it exists to
  cut backtracking through already-cleared routes, not to skip new ones.

## Run Reports

Every strict run finalizes exactly one comprehensive Run Report the moment it
ends, at whichever terminal outcome comes first:

- **Victory** — reaching the Champion / Hall of Fame.
- **Wipe** — losing your last usable Pokémon anywhere (party, every PC box,
  and Daycare), independent of whichever whiteout setting is active.

The report captures the full context: the run's identity (seed, ROM/
randomizer/ruleset versions, preset, enabled generations), the terminal
result, play time and progression state, a complete statistics summary
(encounters, catches, failed/killed/fled/run-from encounters, Dupes/Shiny
encounters, Balls thrown, evolutions, Level to Cap uses, badges, deaths),
your full death history in order, and either your complete winning team
(Victory) or your complete final party exactly as it stood **immediately
before** run-loss cleanup would have destroyed anything (Wipe) — species,
nickname, level, types, ability, held item, moves with PP, IVs, EVs,
calculated stats, current HP/status, Ball, and where/when it was met.

**It's saved straight to your save file** the instant the run ends — you
don't need to save manually first, and it survives a reset or fully closing
and reopening the game. **Finishing a run never affects any later run**:
nothing about randomization, species pools, or eligibility is ever
influenced by a past Run Report, Victory, or Wipe.

### Exporting a report

The report lives in the save file, but you read it as JSON from your
computer:

```sh
python3 tools/export_run.py <save-file>
```

This is the required, always-available path. It's strictly read-only — it
never modifies the save it reads (verified by re-checking the file's size
and modification time before and after) — and it refuses to overwrite an
existing output file unless you pass `--force`. Useful flags:

- `-o DIR` — where to write the JSON (default: current directory)
- `--all` — export every valid report currently in the save, not just the
  newest
- `--slot N` — export one specific report slot
- `--json-only` — skip expanding species/move/item names from this
  repository's headers (useful if you're running the script outside a
  checkout of this repo)

Output files are named `run_<seed>_victory.json` or `run_<seed>_wipe.json`,
with human-readable names alongside every numeric ID, and a schema version
so future tooling can tell old and new report formats apart.

If you'd rather not run the exporter by hand after every run, an optional
poller does it for you automatically while you play in an emulator:

```sh
python3 tools/watch_run_export.py <save-file>
```

It watches the save file for changes and exports a newly-finalized report
within a couple of seconds, without ever touching gameplay state — a
host-side ledger (kept next to the exported files) tracks which report IDs
have already been exported, so the same finalized report is never written
out twice, and replaying the same seed a second time still gets its own
distinct report. Core gameplay never depends on this poller running; the
manual exporter above is always the reliable fallback, and the game itself
never claims a JSON file exists on your computer — it only ever tells you
the report was saved to your save file.

## Building and troubleshooting

This project builds entirely from source; **no baserom is needed and none
should be added.**

```sh
make -j$(sysctl -n hw.ncpu)   # normal parallel build
make clean                    # remove all build output
make debug                    # debug build
```

Toolchain installation is unchanged from upstream `pokeemerald-expansion` —
see [`INSTALL.md`](INSTALL.md) for OS-specific setup. `rom.sha1` intentionally
will not match your build; that file only verifies an *unmodified* decomp
build, and this is not one.

If you're setting up the optional automatic export poller for an emulator,
just point `tools/watch_run_export.py` at wherever that emulator writes its
`.sav` file for this ROM and leave it running in a terminal alongside your
session — no in-emulator scripting or plugin is required, since the poller
only ever reads the `.sav` file from disk.
